# Olivia Chen Ching Hui — Academic E-Profile

A responsive one-page academic profile designed for GitHub Pages.

## Files

- `index.html` — site content and structure
- `styles.css` — visual styling and responsive layout
- `script.js` — mobile navigation, reveal animation and scroll progress

## Publish with GitHub Pages

1. Create a new GitHub repository, e.g. `olivia-academic-profile`.
2. Upload all files from this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Save. GitHub will provide the public Pages URL.

## Recommended customizations

### Add a professional portrait
Replace the `OC` profile orb in `index.html` with an `<img>` tag. Example:

```html
<div class="profile-orb photo-orb">
  <img src="assets/profile.jpg" alt="Olivia Chen Ching Hui">
</div>
```

Then add the image as `assets/profile.jpg`.

### Add academic links
Consider adding links for:
- UNIMAS staff profile
- ORCID
- Google Scholar
- ResearchGate
- LinkedIn
- GitHub

### Privacy
The public version intentionally omits the home address and phone number contained in the source CV.
